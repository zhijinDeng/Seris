# 质量风险主动管控手册

## 标准闭环

1. 感知：设备告警、参数漂移、视觉缺陷、检测不合格或人员上报进入事件流。
2. 关联：按工位、设备、VIN、时间窗和工序顺序拼接上下文。
3. 检索：GraphRAG沿图谱路径检索FMEA、控制计划、历史案例和维修记录。
4. 推理：结合工艺窗口、趋势、连续性、严重度和因果方向形成根因假设。
5. 行动：生成隔离、复检、点检、参数复核、责任确认等任务。
6. 关闭：校验处置记录、复检结果、设备状态和质量负责人确认。
7. 学习：把根因、措施、结果和阈值调整写回知识底座。

## 风险分级

P1：安全、法规、结构强度或关键连接件风险；连续复现；影响车辆或批次已进入后续工序；历史案例匹配高。

P2：非安全关键项但已越过工艺窗口；影响范围可控；需要当班复检或点检。

P3：轻微波动或观察项；进入趋势跟踪，不立即拦截。
