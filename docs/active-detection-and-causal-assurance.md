# 主动预警与因果保障设计

## 一、要解决的现场问题

高自动化产线最危险的并不总是已经越过硬阈值的报警，而是尚未形成终检缺陷、却在多个弱信号中持续积累的风险。例如拧紧扭矩均值缓慢下移、焊接电流CUSUM偏移、风门指令与反馈残差扩大、压铸水路流量波动。单个信号可能不足以停线，但若同时关联关键质量特性、连续VIN/批次和设备退化知识，就应在缺陷显性化前形成可行动风险线程。

本方案将“主动发现”定义为：在下游检验或客户可感知缺陷出现之前，统计检测器至少一项触发、知识关系命中且可圈定影响对象，由此形成可行动风险线程。四场景18至46分钟前置量由带时间戳序列实际运行EWMA/CUSUM并计算，不从页面文案读取；它们只验证机制，不代表现网收益。

## 二、四级主动检测栈

1. 数据质量门：检查时间戳、采样频率、缺失率、量纲、设备与VIN/批次绑定；核心点位缺失时只告警数据问题，不进入自动派单。
2. 硬规则层：工艺上下限、连续越界、设备寿命、报警组合和关键质量特性严重度，保证安全规则优先于模型。
3. 弱信号层：EWMA识别均值小幅漂移，CUSUM积累持续偏差，指令-反馈残差识别执行机构退化；算法阈值按工位、车型和配方分层管理。
4. 知识共识层：把异常信号与设备、工位、FMEA、控制计划、历史8D、维修记录和VIN/批次关系交叉校验，只有满足最小证据组合才生成P1/P2风险线程。

前置量按`T_downstream - T_actionable`计算，其中`T_actionable`是风险线程首次满足派单阈值的事件时间，`T_downstream`是现行下游检验理论可发现该缺陷的时间。试点期同时记录误报、漏报、提前量分布和人工驳回原因，防止只追求提前而制造告警疲劳。

## 三、因果护栏

GraphRAG输出的是候选根因，不是未经验证的事实。每个事件保留Top-3假设，并为每个假设保存支持证据、冲突证据、反证动作和置信度。进入处置建议前必须通过五项护栏：原因信号早于质量偏离；关系符合设备与工艺机理；同设备、同工位或同批次具有复现性；存在可以改变证据强度的干预或对照；数据版本、时间戳和来源可追溯。

以拧紧事件为例，Top-1“套筒磨损叠加校准漂移”由同点位连续复现、扭矩与角度联动、历史案例支持，但与“套筒账面寿命尚未到阈值”存在冲突。系统因此不直接宣告根因，而是生成“更换套筒并用标准件复校”的反证动作。干预后扭矩恢复则增强该假设；若不恢复则降低置信度并提升螺纹摩擦系数或配方错配等候选原因。

## 四、确定性关闭门

事件关闭不依赖模型一句“可以关闭”，而由五个结构化强制项共同决定：源数据完整；影响范围锁定；物理复检通过；授权人员确认；任务、附件和知识回写完成。P1任何一项未通过只能保持隔离或升级。数字员工不直接修改PLC/SCADA参数，不替代车辆或零件放行，不自动关闭P1。

关闭判定由规则引擎执行，大模型只负责解释缺失项和生成协同草案。每次状态变化记录操作者、时间戳、前后值、证据附件和规则版本，形成审计链。

## 五、一车一因果链

一车一因果链不是新增一份静态档案，而是以VIN或零件批次为索引保存经过工位、设备和程序版本、参数窗口、异常事件、风险传播、隔离/复检、人工放行与知识回写。网页可在同一事件内切换不同VIN或零件，查看每个对象的过站时间和处置状态，体现影响范围不是一段概括文字，而是可查询、可收敛、可审计的对象集合。

## 六、试点验收

| 能力 | 计算口径 | 90天目标 |
| --- | --- | --- |
| 缺陷显性化前置量 | `T_downstream - T_actionable`的中位数 | 不少于10分钟 |
| P1召回率 | 被专家确认的P1中系统成功识别数量/全部P1 | 不低于95% |
| 根因Top-3命中率 | 最终根因出现在系统Top-3的事件数/已复盘事件数 | 不低于80% |
| 影响范围准确率 | 正确圈定且无漏放对象数/应圈定对象数 | 不低于90% |
| 关闭门完整率 | 五项强制字段完整的关闭事件数/全部关闭事件数 | 100% |
| 越权操作 | 未授权控制、放行或关闭次数 | 0 |

四类演示场景共用事件模型、Agent状态机、飞书字段和关闭门，只替换感知适配器、工艺本体模块、检测规则和物理验证方法。该资产化方式可向电驱、电池包、整车标定和供应链来料质量扩展。

## 七、反事实证据状态机

干预按`idle → armed → awaiting_measurement → signed → accepted/rejected`推进。选择干预只进入`armed`，必须提交实测项目、验收准则、量具或检测状态和检测岗位签署。只有`accepted`才能通过干预护栏和物理证据门；`rejected`会降低原假设并重排Top-3。事件护照同时纳入信号序列、规则集、知识快照、特征Schema、干预结果、签署和关闭状态。

## 八、策略守卫与安全降级

所有派单、确认和关闭动作统一经过策略守卫。L0影子模式禁止外部写入和关闭；数据延迟冻结新增派单、确认与关闭；图谱不可用转规则只读和人工复核；飞书中断写入Outbox，任务状态显示“待补偿”，恢复后按事件ID补偿一次。网页故障演练会实际改变按钮和任务状态。
