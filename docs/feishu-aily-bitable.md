# 飞书Aily与多维表格落地

## Aily角色设定

名称：赛力斯质量管控AI数字员工。

职责：主动巡检异常、解释风险、生成证据链、调用工具创建任务、提醒责任人、沉淀复盘知识。

权限：默认只建议，不直接执行停线、批量返工或参数改写；P0/P1动作必须经过质量负责人确认。

## 多维表格设计

1. 工艺设备主数据：设备、工位、参数、阈值、负责人、保养周期。
2. 质量事件：事件ID、风险等级、异常摘要、影响范围、当前状态。
3. 证据链：图谱路径、文档依据、历史案例、传感器趋势。
4. 处置任务：任务类型、负责人、SLA、完成状态、复检结论。
5. 复盘知识：最终根因、有效措施、预防规则、可复用条件。
6. 模型评估：建议是否命中、误报原因、漏报原因、规则优化记录。

## 流转规则

- P0：疑似安全/批量缺陷，立即通知质量负责人和产线负责人，需人工确认隔离范围。
- P1：关键质量特性异常，30分钟内复检并完成初步根因判断。
- P2：趋势漂移或单点异常，进入观察队列并触发设备点检。
- P3：低风险提示，沉淀为周报和规则优化建议。
