# 方案创新亮点

## 1. 从质量问答助手升级为主动巡检数字员工

常规方案通常由工程师提问后，AI再检索文档。本方案将工作方式前移：AI数字员工持续监听工艺参数、设备报警、质检结果和维修状态，主动发现隐性质量风险，并推动处置任务进入飞书闭环。

## 2. 质量因果图谱

本方案把设备、工位、参数、质量特性、缺陷模式、根因、控制计划和处置任务连接成风险传导链。例如：`TQ-17拧紧枪 -> 扭矩偏低 -> 预紧力不足 -> VIN隔离 -> 复检扭矩 -> 套筒更换`。这让AI输出沿制造过程可追溯，而不是泛化描述。

## 3. Graph RAG证据合约

P0/P1级处置方案必须同时具备三类证据：实时参数证据、图谱路径证据、历史案例或控制计划证据。证据不足时，系统只进入观察和补充核验流程，不自动升级高风险任务。

## 4. 飞书质量闭环执行系统

飞书在本方案中承担协同执行层：Aily负责解释和追问，多维表格负责事件、证据、任务和复盘结构化，Webhook负责快速播报，SLA字段负责催办，任务关闭后回写复盘知识。

## 5. 人机共治安全闸

制造现场的停线、批量隔离、参数改写等动作不能由AI直接执行。本方案设置P0/P1人工确认门：AI负责定位风险、组织证据、生成处置方案和待确认任务，关键动作由质量负责人确认后执行。

## 6. 质量记忆飞轮

每次处置结果都会沉淀为复盘知识：最终根因、有效措施、误报原因、漏报原因和预防规则会回写知识图谱、历史案例库和FMEA条目，形成持续增长的工厂质量记忆。

## 7. VIN级影响范围计算

系统把异常时间窗、工位、设备、VIN流转、批次和工艺参数关联起来，输出车辆级影响范围。以总装拧紧异常为例，系统能够定位到 `VIN尾号8123-8125` 需要隔离和复检。

## 8. 三张卡机制

一次质量异常进入系统后，自动形成三类结构化输出：

| 卡片 | 内容 | 价值 |
| --- | --- | --- |
| 风险卡 | 风险等级、影响范围、疑似根因 | 支撑快速判断严重性 |
| 证据卡 | 参数越界、图谱路径、历史案例、控制计划 | 支撑可解释和可审计 |
| 任务卡 | 隔离、复检、校准、维修、复盘 | 支撑飞书协同执行 |
