# 质量风险数字员工试点验收协议

## 一、验收对象与边界

验收对象是知质·灵巡在指定工序、指定设备和批准数据范围内的质量风险发现、证据组织、协同处置与关闭保障能力。试点不授予PLC/SCADA写权限，不替代质量放行，不把网页仿真签署视为生产电子签名。企业数据负责人、质量负责人、设备/工艺代表和项目负责人共同签署基线、金标准与Go/No-Go结论。

## 二、样本与金标准

以“一个独立质量风险线程”为统计单位。历史回放集与试点观察集按工序、班次、设备新旧、车型/批次和风险等级分层，来自同一根因事件的相邻记录只进入同一数据分组，禁止跨训练、标定和盲测集泄漏。每类试点工序历史回放不少于50条有效事件，P1样本不足时单独报告精确置信区间，不以普通事件稀释重大漏判。

金标准由两名具备现场资格的质量/工艺专家独立标注风险等级、影响范围和最终根因；不一致项由第三名质量负责人仲裁。基线冻结日期、规则版本、知识快照、数据Schema和盲测清单在试验前签署，试验期间变更必须单独成组统计。

## 三、指标合同

| 指标 | 影子准入 | 协同发布 | 统计口径 |
| --- | --- | --- | --- |
| P1召回率 | 不低于95% | 不低于95% | 金标准P1中被系统在下游显性点前识别的比例 |
| 误报率 | 不高于15% | 不高于10% | 被人工最终驳回的可行动风险/全部可行动风险 |
| Top-3命中率 | 不低于80% | 不低于80% | 最终根因是否进入冻结版本Top-3 |
| 影响范围准确率 | 不低于90% | 不低于95% | 系统圈定对象与最终隔离对象的交并比 |
| 前置量中位数 | 不少于10分钟 | 不少于10分钟 | 下游理论显性时刻减去可行动时刻 |
| P1派发时长 | 仅观测 | 小于1分钟 | 可行动时刻至飞书任务创建回执 |
| 五门完整率 | 100% | 100% | 已关闭P1的五项独立证据状态全部通过 |
| 越权成功 | 0 | 0 | 未授权写控制层、放行、跳态或自批自关 |

每项报告点估计、样本量与95%置信区间，并按工序、班次和风险等级给出分层结果。定位时间、重复问题等改善指标以冻结的人工基线为对照，不只报告平均值。

## 四、Go/No-Go与停用门

出现P1重大漏判、控制层越权写入、未经授权放行、审计记录不可追溯或五门缺失仍关闭时，立即No-Go并回退只读。Top-3连续两周低于70%、误报连续两周高于影子期20%或协同期15%、关键字段完整率低于95%、影响范围漏圈定超过批准阈值时，暂停该工序自动派单并进入专项复盘。飞书、知识服务或数据链路故障必须验证冻结、只读降级和Outbox补偿，不得绕过P1隔离。

只有在不少于30天影子运行、至少三类异常完成端到端闭环、职责分离与企业角色映射验收、飞书原生审批和事件回写可审计、上述硬门全部通过后，才允许从L0进入L2。L3必须另行完成OT安全评审、服务端策略发布、MES白名单和变更审批，浏览器不提供启用入口。

## 五、签收证据包

签收包至少包含原始样本哈希、事件与采集时间、Schema版本、设备/工位/点位/校准ID、关系图查询轨迹、文档来源片段、Top-3及反证结果、影响对象清单、飞书任务和审批实例ID、复检附件、角色签署、状态迁移审计、规则与知识版本、故障演练记录、分层指标明细和最终Go/No-Go会议纪要。
