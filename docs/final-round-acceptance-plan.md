# 决赛作品验收说明

## 成果组成

作品由四类可验证成果组成：企业级互动工作台用于展示主动感知与闭环执行；质量知识底座样例用于证明本体、图谱和案例结构；飞书在线对象用于证明Base、任务和复盘文档能够真实创建与关联；参赛文档用于说明企业需求、系统架构、创新点、量化价值、实施路线和安全边界。

## 功能验收

系统应完成四类场景切换、时间序列EWMA/CUSUM计算、前置量追溯、P1/P2分级、GraphRAG路径、Top-3及反证、VIN/零件级影响圈定、反事实实测与检测签署、后验重排、决策前护栏、关闭前确定性门、三态模式、策略阻断、故障降级、Outbox补偿、事件护照导出和责任链展示。飞书侧应能解析在线Base、按事件ID写入记录、创建幂等任务并生成包含任务块的复盘文档。

## 可信性验收

每条根因结论必须标明为假设并附证据；选择干预不得直接通过物理复检，须存在实测、验收准则和检测签署；P1事件未经风险受理、检测证据和最终授权不得关闭；L0模式、数据过期和知识失效必须实际阻断相应动作；演示工艺值与身份明确标注为脱敏仿真；量化指标按已核验成果、仿真结果和90天实测目标分层。

## 工程验收

前端脚本通过语法检查，桌面与移动端完成截图检查，无文本重叠、空白画布或关键控件溢出。PowerShell编排脚本同时通过干跑和真实调用；DOCX由Markdown统一生成并逐页渲染检查；材料审计检查禁用词、文件数量、关键链接和主文档完整性；Git仅提交项目文件，不提交飞书访问令牌、应用密钥或个人目录。
