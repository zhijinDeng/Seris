# 决赛作品验收说明

## 成果组成

作品由四类可验证成果组成：企业级互动工作台用于展示主动感知与闭环执行；质量知识底座样例用于证明本体、图谱和案例结构；飞书在线对象用于证明Base、任务和复盘文档能够真实创建与关联；参赛文档用于说明企业需求、系统架构、创新点、量化价值、实施路线和安全边界。

## 功能验收

系统应完成四类场景切换、异常注入、弱信号与缺陷显性化前置量展示、P1/P2分级、GraphRAG路径展示、Top-3根因及反证动作、VIN/零件级影响圈定、五项因果护栏、自定义追问、任务编排、人工确认、确定性关闭校验、证据包导出和知识回写状态展示。飞书侧应能解析在线Base、读取13字段表结构、按事件ID写入记录、创建幂等任务并生成包含任务块的复盘文档。

## 可信性验收

每条根因结论必须标明为假设并附证据；每条证据必须对应数据、规则、文档或历史案例；P1事件未经人工确认不得关闭；数据缺失或模型低置信时应降级；演示工艺值明确标注为脱敏仿真，不冒充企业真实数据；量化指标明确标注为试点目标，不包装为已实现收益。

## 工程验收

前端脚本通过语法检查，桌面与移动端完成截图检查，无文本重叠、空白画布或关键控件溢出。PowerShell编排脚本同时通过干跑和真实调用；DOCX由Markdown统一生成并逐页渲染检查；材料审计检查禁用词、文件数量、关键链接和主文档完整性；Git仅提交项目文件，不提交飞书访问令牌、应用密钥或个人目录。
