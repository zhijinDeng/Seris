# 系统架构

## 总体结构

系统分为数据接入、知识底座、推理决策、数字员工和协同执行五层。

- 数据接入：PLC、SCADA、MES、QMS、视觉检测、设备点检、维修记录、飞书任务状态。
- 知识底座：设备、工位、工序、参数、质量特性、缺陷模式、FMEA、控制计划、VIN、人员和任务。
- 推理决策：工艺窗口越界、SPC趋势、时空连续性、GraphRAG检索、因果路径约束、风险分级。
- 数字员工：主动巡检、证据解释、任务编排、状态追问、关闭校验、知识回写。
- 协同执行：飞书Aily、多维表格、机器人卡片、班组看板。

## 数据模型

核心三元组包括：

- 设备 位于 工位
- 工位 执行 工序
- 工序 产生 参数
- 参数 影响 质量特性
- 质量特性 关联 缺陷模式
- 缺陷模式 对应 FMEA条目
- FMEA条目 绑定 控制计划
- 异常事件 影响 VIN或零件批次
- 处置任务 分派 责任角色
- 关闭结果 回写 知识图谱
