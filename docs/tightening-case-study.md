# 完整案例：总装底盘螺栓拧紧风险闭环

## 1. 场景背景

总装底盘合装工位对连接件预紧力要求高。传统做法通常依赖拧紧系统报警、质量工程师跨系统查询、设备工程师人工排查。问题在于：单次扭矩偏低可能是偶发，但连续多车同点位偏低往往意味着工装磨损、拧紧枪校准漂移或程序参数异常，若不能及时隔离影响VIN，后续返修成本会迅速扩大。

## 2. 异常输入

| 字段 | 值 |
| --- | --- |
| 事件ID | E-20260717-001 |
| 产线/工位 | 总装一线 / 底盘合装-拧紧工位 |
| 设备 | TQ-17智能拧紧枪 |
| 参数 | M12底盘螺栓扭矩 |
| 实测值 | 86.4 N·m |
| 工艺窗口 | 92.0-108.0 N·m |
| 报警 | 连续3辆车同点位低于下限 |
| 影响范围 | VIN尾号8123-8125 |
| 质量风险 | 底盘连接件预紧力不足 |

## 3. Graph RAG证据链

1. 图谱定位：`TQ-17智能拧紧枪 -> 底盘合装-拧紧工位 -> M12底盘螺栓扭矩 -> 底盘连接件预紧力`。
2. 规则证据：实测值低于工艺窗口下限，且同点位连续发生，风险高于单点偶发。
3. 历史案例：`C-009` 显示同类现象曾由套筒磨损或扭矩校准偏移引起。
4. 控制计划：该类关键连接件需要复检扭矩并隔离影响VIN，不能直接放行。
5. 维修知识：若套筒寿命接近上限，应检查套筒磨损并完成拧紧枪校准。

## 4. Agent判断

| 输出 | 结果 |

| 处置原则 | 先隔离、再复检、再校准、最后复盘 |

## 6. 最终复盘样例

复盘结论：TQ-17对应套筒存在磨损，导致同点位扭矩偏低。已完成受影响VIN复检、套筒更换、拧紧枪校准和参数复核。新增预防规则：当同一拧紧枪同一螺栓点位连续2辆车低于下限且套筒寿命超过80%时，自动提升为P1并创建点检任务。

- 处置效率：由群消息沟通变成任务化SLA推进。
- 知识沉淀：由个人经验变成可检索的复盘知识和图谱规则。
