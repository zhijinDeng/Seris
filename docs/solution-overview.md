# 方案总览

## 一句话定位

赛力斯质量管控AI数字员工，是一套面向超级工厂的主动质量风险管控方案。系统能够感知工艺或设备异常，调用质量知识图谱与Graph RAG形成证据链，并通过飞书Aily、多维表格和任务机制推动处置闭环。

## 方案价值

1. 看见异常：监听MES、SCADA、PLC、QMS、EAM和视觉检测数据。
2. 理解风险：用设备-工艺-质量因果图谱判断异常后果。
3. 组织证据：用Graph RAG生成参数、路径、案例和控制计划证据。
4. 推动行动：在飞书里生成任务、提醒责任人、跟踪SLA。
5. 复盘成长：把最终根因和有效措施回写知识库与FMEA。

## 差异化优势

| 维度 | 常规方案 | 本方案 |
| --- | --- | --- |
| AI角色 | 被动问答助手 | 主动巡检和协同执行的质量数字员工 |
| 推理依据 | 文本相似度检索 | 质量因果图谱与Graph RAG证据链 |
| 影响范围 | 人工按经验估计 | 结合VIN、时间窗、工位自动锁定 |
| 协同执行 | 群消息和人工催办 | 飞书事件、证据、任务、SLA、复盘全链路 |
| 长期价值 | 单次分析结束 | 每次处置反哺FMEA、案例库和知识图谱 |

## 系统运行入口

- `app/index.html`：异常事件、证据链、处置任务和飞书动作。
- `app/innovation.html`：方案创新亮点。
- `scripts/run_quality_agent.py`：质量Agent推理输出。
- `scripts/feishu_client.py`：飞书接口数据预览与集成。
- `diagram/quality-ai-architecture.svg`：完整闭环架构图。
