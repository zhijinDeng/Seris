# 系统运行与演示说明

## 运行入口

下载仓库后直接打开`app/index.html`，无需安装前端依赖。页面包含实时管控、企业数据、知识推理、飞书协同和价值验证五个工作域，支持桌面与移动端。

## 七分钟演示路径

第一分钟进入“企业数据”，说明625类设备、9673台实例、336项功能、1287条故障模式和406张工单均来自赛事提供的脱敏数据。第二分钟点击“启动闭而未解审计”，观察数字员工定位到某安全防护设备121张工单中119张已关闭、120张原因未知、0张关联故障模式。第三分钟打开证据链，说明系统只提出两条待验证的故障模式候选，不自动确认根因，并生成现场检查、故障模式确认、复机确认和标准更新任务。第四至第七分钟再切换“总装底盘合装拧紧”仿真，展示EWMA/CUSUM前置22分钟、VIN圈定、Top-3反事实重排、飞书派发和五门关闭。这样先证明作品读懂企业真实数据，再用可控仿真证明主动感知与受控执行机制。

## 必看交互

- 动态产线态势：场景切换后，关注产线、风险等级和回放时间同步变化。
- 企业数据审计：展示工单关闭状态与知识闭环状态的差异，并可打开类型、功能、同类设备和故障模式候选的关系路径。
- 回答依据：每个数字员工回答绑定E1/E2、`QG-2026.08`和`KG-18.0`。
- 关系图检索：CLI输出6步有界查询轨迹、来源片段和原始样本哈希。
- 反事实重排：稳定H编号与Rank分离，避免把“原H2升为首因”错误改名为H1。
- 分层关闭：现场处置五门分别保存，关闭动作只读取状态；标准审批、主平台回写和有效性观察由知识债事件继续跟踪。
- 六对象飞书链：知识债事件、诊断任务、现场检查、复机确认、标准变更审批和设备平台回写回执。
- 权限边界：L0阻断外部动作，浏览器不能授予L3；数据、图谱或飞书故障进入冻结、只读或Outbox。

## 现场边界

企业数据页只使用赛事提供数据包的汇总结果与脱敏编码；原始Excel和Word不进入公开仓库。四个工艺场景中的参数、VIN、实测结果和岗位身份为工程仿真。生产签署必须由服务端保存企业身份、角色、量具ID、附件、审批实例和不可覆盖时间戳，并执行职责分离。系统不直接写PLC/SCADA，不替代质量放行，不自动关闭P1，也不把候选故障模式自动写回主平台。
