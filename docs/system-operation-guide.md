# 系统运行与演示说明

## 运行入口

直接打开`D:\赛力斯\app\index.html`即可运行决赛工作台，无需安装前端依赖。页面包含实时管控、知识推理、飞书协同和价值验证四个工作域，支持桌面与移动端自适应。

## 七分钟演示路径

第一分钟展示事件队列和生产态势，选择“总装底盘合装拧紧”。第二分钟点击“注入下一工况”，观察事件从主动感知、图谱收敛、证据推理推进到飞书执行。第三分钟查看工艺趋势与P1安全门，说明系统只提出隔离和复检建议，不替代放行。第四分钟在数字员工窗口追问根因、影响VIN和证据链。第五分钟点击“派发飞书闭环”，展示Base、卡片、任务和复盘文档四段流程。第六分钟完成人工确认和验证关闭，观察任务状态、时间线和知识回写变化。第七分钟打开在线Base、飞书任务和复盘文档，证明不是静态空架子。

## 核心交互

- 风险事件队列：四类仿真工况保持独立参数、证据、影响范围和任务。
- 工艺趋势：显示实时值、控制上下限和越界趋势。
- 数字员工窗口：支持快捷问题和自定义问题。
- 处置编排：必须先派发、再人工确认、最后验证关闭。
- 完整证据包：展示原始证据、根因假设和关闭条件，并可导出JSON。
- GraphRAG路径：展示设备—参数—质量风险—历史案例—根因的多跳关系。
- 一车一因果链：展示事件时间窗到VIN/批次、处置与关闭门的映射。
- 飞书在线证明：直接跳转事件表、任务和复盘文档。

## 现场边界

演示数据为脱敏仿真数据，数值用于说明系统机制，不代表赛力斯真实工艺参数。生产接入时由企业确认数据字典、质量等级、工艺窗口、责任角色和放行权限。系统支持降级为只读监测：当数据延迟、关键点位缺失、模型连续低置信或人工结论冲突时，停止自动派单并保留审计记录。
