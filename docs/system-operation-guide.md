# 系统运行与演示说明

## 运行入口

下载仓库后直接打开`app/index.html`，无需安装前端依赖。页面包含实时管控、知识推理、飞书协同和价值验证四个工作域，支持桌面与移动端。

## 七分钟演示路径

第一分钟选择“总装底盘合装拧紧”，说明顶部只点亮当前事件对应产线，回放时钟来自工况时间而非电脑时间。第二分钟点击“注入下一工况”，观察主动感知、图谱收敛、证据推理和飞书执行。第三分钟解释EWMA/CUSUM弱信号、22分钟前置量和影响VIN。第四分钟在协同窗口追问根因与关闭条件，点击E1/E2、规则包或知识版本打开证据包。第五分钟执行反事实动作，说明H1/H2/H3身份固定、Rank随证据变化；焊装回路试验可展示H2由Rank 2升至Rank 1。第六分钟依次执行派发、人工确认和“验收任务与回写”，观察五项关闭门独立变化。第七分钟完成关闭，打开Base写入回读证据、任务和文档对象样例，再展示生产试点就绪门。

## 必看交互

- 动态产线态势：场景切换后，关注产线、风险等级和回放时间同步变化。
- 回答依据：每个数字员工回答绑定E1/E2、`QG-2026.08`和`KG-17.4`。
- 关系图检索：CLI输出6步有界查询轨迹、来源片段和原始样本哈希。
- 反事实重排：稳定H编号与Rank分离，避免把“原H2升为首因”错误改名为H1。
- 五门关闭：源数据、范围、物理复检、授权和任务/知识回写分别保存；关闭动作只读取状态。
- 六对象飞书链：事件台账、处置任务、复检记录、设备维修、原生审批和复盘知识。
- 权限边界：L0阻断外部动作，浏览器不能授予L3；数据、图谱或飞书故障进入冻结、只读或Outbox。

## 现场边界

工艺参数、VIN、实测结果和岗位身份为脱敏仿真数据。生产签署必须由服务端保存企业身份、角色、量具ID、附件、审批实例和不可覆盖时间戳，并执行职责分离。系统不直接写PLC/SCADA，不替代质量放行，不自动关闭P1。
