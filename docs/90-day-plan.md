# 90天落地计划

## 0-30天：试点建模

- 选择总装拧紧、焊装焊点、涂装烘干三类场景。
- 梳理设备台账、工艺参数、FMEA、控制计划、质检报告、维修记录。
- 建立最小可用本体和100-300个核心图谱节点。
- 打通多维表格事件、证据、任务、复盘字段。

## 31-60天：闭环试运行

- 接入样例实时数据或分钟级批量数据。
- 上线异常检测、子图召回、证据链生成和任务派发。
- 每周复盘误报、漏报、建议不可执行原因。
- 形成三类场景的标准处置模板。

## 61-90天：规模化复制

- 扩展到更多设备、更多质量特性和更多工位。
- 建立风险等级、人工确认、SLA、复盘沉淀制度。
- 输出指标看板：定位时长、重复问题、任务逾期、建议命中率。
- 为后续接入真实图数据库、向量库和飞书开放平台API预留接口。
