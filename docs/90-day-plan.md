# 90天落地与验收计划

## 总体原则

试点采用“历史回放—影子运行—协同闭环—受控推广”的顺序。知质·灵巡始终定位为质量决策支持与协同执行层：首期不直接修改PLC/SCADA参数，不替代质量放行，不自动关闭P1事件。每一阶段均设置进入条件和退出条件，防止模型精度尚未稳定时扩大生产影响。

## 第1—30天：数据与知识底座成型

试点选择总装拧紧和焊装点焊两类高价值工况。完成MES过站、设备参数、质量检测、点检维修、FMEA、控制计划和历史8D的字段对齐，建立设备、工位、工序、参数、质量特性、缺陷模式、VIN/批次、责任角色和处置任务本体。采用最近6—12个月事件做离线回放，形成不少于100条可核验风险线程。

阶段验收包括：关键字段完整率不低于95%；设备—工位—工序映射准确率不低于98%；VIN/批次时间窗可追溯率达到100%；高质量历史案例入图不少于100条；数据脱敏、分级权限与审计日志策略完成验收。

## 第31—60天：影子运行与人机标定

上线数据质量门、工艺规则、EWMA/CUSUM/响应残差、GraphRAG证据检索、根因Top-3和因果护栏。系统在当班实时输出风险等级、缺陷显性化前置量、影响范围、支持/冲突证据、反证动作和处置建议，但不改变既有控制与放行流程。质量、设备、工艺工程师对每条建议执行“采纳、修改、驳回”反馈，驳回原因进入评测集。

飞书侧启用质量事件Base、P1/P2消息通知、任务中心和复盘文档。事件ID作为Base记录、飞书任务、消息幂等键和复盘文档的共同主键。阶段验收包括：缺陷显性化前置量中位数不少于10分钟；P1召回率不低于95%；误报率控制在15%以内；根因Top-3命中率不低于80%；证据可追溯率达到100%；从触发到飞书任务生成小于1分钟。

## 第61—90天：协同闭环与价值验证

在总装、焊装稳定后扩展涂装烘干和压铸冷却工况。启用任务状态事件订阅、超时升级、复检附件归档和五项确定性关闭门。P1事件只有在源数据完整、范围锁定、物理复检、授权确认和知识回写全部通过后关闭，P2事件按控制计划和复检结果处理。关闭结果回写设备—症状—根因—措施关系及反证结果，形成可复用知识。

阶段验收包括：任务按期关闭率不低于90%；已关闭P1五项关闭门完整率为100%；全部事件过程记录字段完整率不低于95%；复盘知识沉淀率不低于90%；异常定位时间较人工基线下降40%—60%；同类重复问题在连续三个月窗口内下降15%—25%。上述指标均以试点期实测为准，不作为既成收益陈述。

阶段内同时完成三类故障演练：核心数据过期时冻结派单，知识服务不可用时切换规则与控制计划只读包，飞书不可用时进入Outbox并完成一次无重复补偿。L0影子模式不得产生外部任务或关闭结论，越权成功操作必须为0。

## 推广门槛

满足以下条件后进入下一产线：完成不少于30天影子运行；至少三类异常完成端到端闭环；P1无漏判重大事件；根因Top-3命中率达到80%；关键数据延迟满足业务窗口；责任角色、放行权限和应急降级机制通过企业验收。推广模板统一为“数据契约—本体模块—规则包—案例集—飞书流程—验收指标”，可复制到电驱装配、电池包气密、整车标定、供应商来料质量和路试问题闭环。
