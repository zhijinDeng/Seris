# 评委速读页

## 一句话定位

赛力斯质量管控AI数字员工，是一名能主动发现工艺/设备异常、调用质量知识图谱和Graph RAG推理证据链、再通过飞书Aily与多维表格推动处置闭环的AI工程师。

## 为什么不是普通平台

普通平台展示数据，本方案让AI执行质量工作流：

1. **看见异常**：监听MES、SCADA、PLC、QMS、EAM和视觉检测数据。
2. **理解风险**：用设备-工艺-质量因果图谱判断异常后果。
3. **组织证据**：用Graph RAG生成参数、路径、案例、控制计划证据链。
4. **推动行动**：在飞书里生成任务、提醒责任人、跟踪SLA。
5. **复盘成长**：把最终根因和有效措施回写知识库与FMEA。

## 最能打动评委的亮点

| 亮点 | 传统做法 | 本方案 |
| --- | --- | --- |
| 主动性 | 工程师看到报警后再查 | AI主动巡检并升级风险 |
| 可解释性 | 大模型直接给建议 | 每条建议带证据链合约 |
| 影响范围 | 人工按经验估计 | 结合VIN、时间窗、工位自动锁定 |
| 协同执行 | 群里发消息、人工催办 | 飞书多维表格任务化闭环 |
| 组织记忆 | 复盘在个人经验里 | 回写图谱、案例库和FMEA |

## 答辩建议话术

“我们的创新不是把大模型接到工厂文档上做问答，而是让AI成为一名有权限边界的质量数字员工。它会主动发现异常，用Graph RAG交付证据链，用飞书推动任务闭环，并把每次处置沉淀成赛力斯自己的质量记忆。”
