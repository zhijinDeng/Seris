# 命题要求对应关系

## 1. 智能制造知识底座

对应做法：以设备、工位、工序、参数、质量特性、缺陷模式、根因、FMEA、控制计划、VIN、零件批次和处置任务构成本体，形成可追溯知识图谱。

可交付产物：`data/quality_ontology.jsonld`、`data/quality_cases.json`、`data/factory_events.csv`、`docs/architecture.md`。

验证方式：任一异常事件都能映射到设备、工位、参数、质量风险、历史案例、处置任务和关闭依据。

## 2. 从感知到行动的自主智能体范式

对应做法：数据质量门、弱信号算法和知识关系先形成多引擎共识，异常在缺陷显性化前触发风险分级、GraphRAG证据检索、VIN/批次范围圈定、Top-3根因与反证动作、任务编排、飞书通知和五项关闭门。

可交付产物：`app/index.html`交互工作台、`scripts/run_quality_agent.py`命令行推理脚本、`data/interactive_scenarios.json`场景数据。

验证方式：点击“注入异常”或运行脚本后，系统能输出弱信号、前置量、风险等级、Top-3假设、支持/冲突证据、反证动作、影响范围、处置动作和飞书记录字段。

## 3. AI数字员工的落地应用

对应做法：知质·灵巡具备岗位职责、权限边界、运行工作台和飞书协同入口，不直接替代质量负责人放行，不直接修改控制层参数。

可交付产物：`docs/digital-employee-profile.md`、`docs/feishu-aily-bitable.md`、`docs/system-operation-guide.md`、`提交材料/07_仿真工况与交互案例.md`。

验证方式：P1/P2事件能进入飞书多维表格字段、责任人任务、机器人卡片和复盘回写链路。

## 4. 业务价值

定位指标：缺陷显性化前置量中位数不少于10分钟，异常定位时间下降40%-60%，P1任务派发小于1分钟，关键工序追溯覆盖100%，根因Top-3命中率达到80%以上，重复质量问题下降15%-25%，复盘知识沉淀率达到90%以上。

推广方式：先离线回放，再影子运行，再飞书协同闭环，最后复制到电驱装配、电池包气密、整车标定、供应链来料和路试问题闭环。

## 5. 决赛可核验对象

网页工作台可逐步演示异常注入、弱信号前置发现、多引擎共识、GraphRAG检索、Top-3假设与反证、VIN/零件切换、任务派发、P1人工确认、五项关闭验证和证据包导出；飞书侧可直接打开质量事件Base、责任任务和复盘文档；本地数据文件可核查本体、因果保障合同、案例、事件、证据轨迹与统一事件载荷。三类对象使用同一个事件ID贯通。

## 6. 企业验收口径

试点只以现场实测判定：P1召回率不低于95%，根因Top-3命中率不低于80%，影响范围准确率不低于90%，任务派发小于1分钟，任务按期关闭率不低于90%，复盘知识沉淀率不低于90%，越权操作为0。所有效率和质量收益只统计被现场采纳并完成闭环的事件。

## 7. 决策保障增量

作品能够直接核验四项关键行为：前置量由时间序列计算而不是固定显示；反事实实测与检测签署驱动Top-3重排；L0与数据失效真正阻断派单和关闭；飞书中断进入Outbox并显示待补偿。决策前因果护栏与关闭前确定性门分开呈现，人工责任细分到风险受理、检测签署和最终授权。
