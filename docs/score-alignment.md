# 命题要求对应关系

## 1. 智能制造知识底座

对应做法：以设备、工位、工序、参数、质量特性、缺陷模式、根因、FMEA、控制计划、VIN、零件批次和处置任务构成本体，形成可追溯知识图谱。

可交付产物：`data/quality_ontology.jsonld`、`data/quality_cases.json`、`data/factory_events.csv`、`docs/architecture.md`。

验证方式：任一异常事件都能映射到设备、工位、参数、质量风险、历史案例、处置任务和关闭依据。

## 2. 从感知到行动的自主智能体范式

对应做法：异常事件自动触发风险分级、GraphRAG证据检索、影响范围圈定、根因假设、任务编排、飞书通知和关闭回写。

可交付产物：`app/index.html`交互工作台、`scripts/run_quality_agent.py`命令行推理脚本、`data/interactive_scenarios.json`场景数据。

验证方式：点击“注入异常”或运行脚本后，系统能输出风险等级、证据链、影响范围、处置动作和飞书记录字段。

## 3. AI数字员工的落地应用

对应做法：知质·灵巡具备岗位职责、权限边界、运行工作台和飞书协同入口，不直接替代质量负责人放行，不直接修改控制层参数。

可交付产物：`docs/digital-employee-profile.md`、`docs/feishu-aily-bitable.md`、`docs/system-operation-guide.md`、`提交材料/07_仿真工况与交互案例.md`。

验证方式：P1/P2事件能进入飞书多维表格字段、责任人任务、机器人卡片和复盘回写链路。

## 4. 业务价值

定位指标：异常定位时间下降40%-60%，P1任务派发小于1分钟，关键工序追溯覆盖100%，根因Top-3命中率达到80%以上，重复质量问题下降15%-25%，复盘知识沉淀率达到90%以上。

推广方式：先离线回放，再影子运行，再飞书协同闭环，最后复制到电驱装配、电池包气密、整车标定、供应链来料和路试问题闭环。
