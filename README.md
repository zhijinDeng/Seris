# 赛力斯质量管控AI数字员工

面向赛力斯超级工厂的设备质量风险主动管控方案。项目目标是用本体论与知识图谱构建工厂设备-工艺-质量知识底座，在此基础上用 Graph RAG 与 Autonomous Agent 打造可主动感知、可推理、可解释、可执行、可复盘的质量管控AI数字员工。

## 目录

- `提交材料/00_报名表填写文本.md`：平台表单 Part 1 / Part 2 可直接粘贴文本。
- `提交材料/01_开题报告.md`：命题理解、洞察、总体思路和创新点。
- `提交材料/02_整体解决方案书.md`：架构、数据链路、智能体闭环、落地价值。
- `提交材料/03_平台原型说明.md`：静态网页与命令行 demo 使用说明。
- `docs/`：研究依据、架构、飞书Aily/多维表格落地、90天实施计划。
- `data/`：本体、异常事件、质量案例、多维表格字段样例。
- `app/index.html`：可打开的前端演示页面。
- `scripts/run_quality_agent.py`：无外部依赖的质量智能体推理 demo。
- `scripts/feishu_client.py`：飞书多维表格、Webhook机器人和Aily提示词的dry-run/真实发送客户端。
