# 赛力斯质量风险主动管控数字员工参赛材料

本项目提交一套面向新能源汽车智能工厂的质量管控数字员工方案，核心对象为“知质·灵巡”。系统以设备、工艺、质量、车辆、人员和处置任务为知识底座，通过GraphRAG、因果约束、规则引擎和飞书协同，把现场异常从“被动查询”推进到“主动捕捉、证据推理、任务派发、闭环复盘”。

## 目录结构

- `提交材料/`：报名表填写文本、开题报告、整体方案书、运行说明、完整案例、创新亮点、仿真工况案例。
- `app/`：可直接打开的交互工作台，包含异常注入、数字员工对话、证据链、知识图谱路径和飞书任务流。
- `data/`：工厂事件样例、质量案例库、本体、飞书字段、公开资料依据和交互场景数据。
- `docs/`：研究依据、系统架构、数字员工设定、飞书集成、落地路线和质量风险手册。
- `scripts/`：本地运行、材料检查和飞书接口封装脚本。
- `diagram/`：质量数字员工架构图。

## 运行方式

1. 打开 `D:\赛力斯\app\index.html` 进入工作台。
2. 点击左侧工况，选择“注入异常”，观察风险升级、证据链、任务看板和飞书记录同步变化。
3. 点击数字员工窗口中的问题按钮，查看根因解释、影响范围、飞书协同和复盘回写逻辑。
4. 命令行运行：`py D:\赛力斯\scripts\run_quality_agent.py`，输出同一批事件的结构化处置结果。
5. 如需接入飞书，将 `data/feishu_env_template.json` 中的占位配置替换为企业应用配置，再运行 `scripts/feishu_client.py`。
