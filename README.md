# 赛力斯质量管控AI数字员工

面向赛力斯超级工厂高精度制造场景，本项目构建“设备-工艺-质量-处置”知识底座，并在此基础上设计具备主动感知、证据推理、协同执行和复盘沉淀能力的质量管控AI数字员工。

## 提交材料

- `提交材料/00_报名表填写文本.md`：报名系统可复制文本。
- `提交材料/01_开题报告.md`：命题理解、业务洞察、总体方案与创新点。
- `提交材料/02_整体解决方案书.md`：系统架构、核心模块、场景闭环与量化价值。
- `提交材料/03_平台运行说明.md`：网页平台、命令行程序与飞书接口运行说明。
- `提交材料/04_参考文献与数据依据.docx`：企业资料、行业资料与技术依据。
- `提交材料/05_系统运行说明与完整案例.docx`：系统运行路径与总装拧紧完整闭环案例。
- `提交材料/06_方案创新亮点.docx`：方案创新点与差异化价值。

## 核心资产

- `app/index.html`：质量管控工作台，可查看异常事件、证据链、处置任务与飞书协同动作。
- `app/innovation.html`：方案创新亮点展示页。
- `diagram/quality-ai-architecture.svg`：从现场数据到复盘回写的完整架构图。
- `data/quality_ontology.jsonld`：工厂质量本体数据。
- `data/end_to_end_trace.json`：从异常感知到飞书执行的闭环链路数据。
- `scripts/run_quality_agent.py`：质量智能体推理程序。
- `scripts/feishu_client.py`：飞书多维表格与机器人消息集成程序，默认以预览模式输出接口数据。
