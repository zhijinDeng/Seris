# 方案创新亮点

## 一句话定位

本方案不是普通质量看板，也不是被动问答机器人，而是一名具备证据推理、权限边界和飞书执行闭环的赛力斯质量管控AI数字员工。

## 1. 主动巡检数字员工

系统持续监听工艺参数、设备报警、质检结果和维修记录，主动识别隐性质量风险。它更接近在线质量工程师，而不是知识库入口。

## 2. 质量因果图谱

知识图谱不仅记录设备、工位和参数，更表达设备状态如何影响工艺参数，工艺参数如何影响质量特性，质量特性如何关联缺陷模式、根因和处置方案。

## 3. Graph RAG证据合约

P0/P1结论必须带实时参数、图谱路径、历史案例或控制计划三类证据。系统不能只给结论，必须交付可审计证据链。

## 4. 飞书质量闭环执行系统

飞书承接事件、证据、任务、SLA和复盘。Aily负责解释和追问，多维表格负责结构化记录，Webhook负责快速播报，任务关闭后回写复盘知识。

## 5. 质量记忆飞轮

每次异常处置都会沉淀最终根因、有效措施、误报/漏报原因和预防规则，持续反哺知识图谱、历史案例库和FMEA，让系统越用越懂产线。

## 6. 三张卡机制

一次质量异常进入系统后，AI自动形成风险卡、证据卡、任务卡。风险卡说明风险等级、影响范围和疑似根因；证据卡说明参数越界、图谱路径、历史案例和控制计划；任务卡说明隔离、复检、校准、维修和复盘任务。

## 7. 运行入口

| 运行项 | 内容 |
| --- | --- |
| `app/index.html` | 异常事件、证据链、处置任务、飞书动作同屏展示 |
| `scripts/run_quality_agent.py` | 从异常自动生成风险、根因和处置方案 |
| `scripts/feishu_client.py --write-interface-data` | 生成飞书多维表格和Webhook接口数据 |
| `diagram/quality-ai-architecture.svg` | 从现场数据到复盘回写的完整闭环架构 |
