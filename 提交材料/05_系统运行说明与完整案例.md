# 系统运行说明与完整案例

## 一、平台定位

本项目的核心是构建一名赛力斯超级工厂质量管控AI数字员工。平台用于展示完整闭环：异常如何进入，知识图谱如何组织证据，Graph RAG如何推理，Agent如何拆分任务，飞书如何承接执行。

## 二、运行路径

1. 打开 `app/index.html`，选择总装拧紧异常 `E-20260717-001`。
2. 查看证据链：总装一线、底盘合装、TQ-17拧紧枪、扭矩偏低、预紧力不足。
3. 查看飞书任务看板：系统将处置动作拆分为隔离、复检、校准、检查套筒等任务。
4. 运行 `python scripts/run_quality_agent.py`，查看风险等级、根因假设、证据链和处置方案。
5. 运行 `python scripts/feishu_client.py --event-id E-20260717-001 --write-interface-data`，生成飞书多维表格记录、Webhook卡片和Aily交互指令。

## 三、完整案例摘要

总装底盘合装工位中，TQ-17智能拧紧枪检测到M12底盘螺栓扭矩为86.4N·m，低于92.0-108.0N·m工艺窗口，并连续3辆车同点位低于下限。AI数字员工将其评为P1风险，沿知识图谱召回“设备-工位-参数-质量特性-缺陷模式-历史案例”证据链，判断疑似根因为套筒磨损或扭矩校准偏移。

处置方案为：暂停该点位自动放行，隔离VIN尾号8123-8125车辆，复检扭矩，校准TQ-17，检查并更换套筒。飞书侧自动写入质量事件表、拆分处置任务、推送机器人卡片，并在任务关闭后沉淀复盘知识。

## 四、赛题要求对应

| 赛题要求 | 本项目回应 |
| --- | --- |
| 智能制造知识底座 | 本体、质量知识图谱、历史案例、控制计划 |
| 从感知到行动 | 异常事件、Agent推理、飞书任务、复盘回写 |
| Graph RAG | 图谱子图召回、文档/案例证据、可解释路径 |
| Autonomous Agent | 风险评分、根因假设、任务拆解、工具调用 |
| 飞书落地 | Aily交互指令、多维表格记录、Webhook卡片、SLA看板 |

## 五、落地路径

方案先从总装拧紧、焊装焊点、涂装烘干三类高价值场景试点，再扩展到更多产线和设备；先用接口数据预览验证飞书数据结构，再接入真实飞书开放平台；先沉淀案例和规则，再持续扩展知识图谱。
