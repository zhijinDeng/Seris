# 平台运行说明

## 一、本地工作台

入口文件：`D:\赛力斯\app\index.html`

运行方式：双击入口文件即可打开“知质·灵巡”工作台。页面左侧为四个仿真工况，中部为数字员工交互窗口，右侧为GraphRAG证据链、飞书协同任务和多维表格记录。

操作路径：

1. 选择“总装底盘合装拧紧、焊装侧围点焊、涂装中涂烘干、一体化压铸冷却”任一工况。
2. 点击“注入异常”，观察系统如何更新风险等级、影响范围、根因假设和任务列表。
3. 点击数字员工窗口中的追问按钮，查看“为什么升级P1、影响哪些VIN、证据链是什么、如何派发飞书任务、关闭后如何复盘”。
4. 点击“关闭任务”，查看任务状态和知识回写状态。

## 二、命令行运行

命令：`py D:\赛力斯\scripts\run_quality_agent.py`

脚本读取`data/factory_events.csv`和`data/quality_cases.json`，完成风险分级、案例检索、证据链生成和飞书记录字段输出。该脚本用于验证工作台背后的数据结构和推理逻辑。

## 三、飞书接入

配置文件：`data/feishu_env_template.json`

接入步骤：

1. 创建飞书企业自建应用，配置应用凭证。
2. 按`data/feishu_bitable_schema.csv`创建质量事件表、处置任务表、复检记录表、设备维修表和复盘记录表。
3. 使用自定义机器人把P1/P2风险卡片推送到质量、设备、工艺和班组群。
4. 在Aily中配置质量事件查询、任务更新和复盘提交入口。
5. 使用`scripts/feishu_client.py`封装新增记录、机器人卡片和事件回调。

系统首期只写协同记录和任务状态，不直接写入控制层参数。
