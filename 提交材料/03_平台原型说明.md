# 平台原型说明

## 静态网页原型

打开 `app/index.html` 即可查看质量管控AI数字员工演示页面。页面包含异常事件流、知识图谱证据链、Agent处置建议、飞书任务看板和指标面板，适合在答辩或补充材料中展示“从感知到行动”的闭环。

## 命令行Agent demo

在项目根目录运行：

```powershell
python scripts/run_quality_agent.py
```

脚本会读取 `data/factory_events.csv` 和 `data/quality_cases.json`，模拟异常评分、图谱证据召回、根因推理和多维表格任务生成。该demo无外部依赖，便于评委快速复现。

## 可扩展接口

- 数据输入：MES、SCADA、PLC、QMS、EAM、视觉检测、工艺文件。
- 工具调用：图数据库查询、向量检索、规则校验、工单创建、飞书消息。
- 人工确认：P0/P1风险建议必须由质量工程师确认后执行停线或批量隔离。
