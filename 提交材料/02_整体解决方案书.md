# 整体解决方案书

## 1. 业务目标

构建一名面向超级工厂高精度制造的质量管控AI数字员工。它不是等待工程师提问，而是持续监听工艺参数、设备报警、质检结果和维修记录，发现隐性质量风险后自动检索知识底座、推理风险链路、生成处置方案，并通过飞书Aily和多维表格推动任务闭环。

## 2. 总体架构

```text
现场数据层：MES / SCADA / PLC / QMS / EAM / 视觉检测 / 维修工单
      ↓
语义治理层：数据清洗、实体对齐、事件标准化、参数阈值管理
      ↓
知识底座层：本体 + 工厂质量知识图谱 + 文档向量库 + 历史案例库
      ↓
Graph RAG层：子图召回、文档召回、多跳路径、证据排序、规则校验
      ↓
Agent层：观察、研判、计划、工具调用、任务派发、复盘学习
      ↓
协同执行层：飞书Aily、多维表格、审批、工单、看板、周报
```

## 3. 核心模块

| 模块 | 功能 | 实际落地方式 |
| --- | --- | --- |
| 工厂质量本体 | 定义车型、工序、设备、参数、报警、缺陷、根因、控制计划、任务 | 先用三类试点工序建核心类，再增量扩展 |
| 知识图谱构建 | 把设备台账、BOM、工艺路线、FMEA、质检报告、维修记录连接起来 | Neo4j/图数据库或RDF图谱均可落地 |
| 异常捕捉 | 捕捉阈值越界、趋势漂移、同点位重复、跨设备关联异常 | 规则引擎 + 时间序列模型 + 质量规则库 |
| Graph RAG | 先查相关子图，再查制度文档、历史案例和维修记录 | 降低幻觉，增强多跳问题解释性 |
| 自主智能体 | 自动判断风险等级、影响范围、隔离/复检/维修建议 | 工具调用受权限、SLA和人工确认约束 |
| 飞书协同 | Aily对话解释，多维表格承接事件、证据、任务和复盘 | 让AI输出进入真实工作流 |

## 4. 典型场景

### 总装螺栓拧紧风险

智能体发现同一拧紧枪连续三辆车扭矩低于下限。它在图谱中定位到工位、枪号、套筒、螺栓规格、阈值、关联缺陷和历史案例，再检索控制计划与维修记录。输出结论：疑似套筒磨损或扭矩校准偏移，建议暂停该点位自动放行、隔离车辆、复检扭矩、校准拧紧枪，并创建设备维护任务。

### 焊装焊点质量风险

智能体发现焊接电流低位漂移，关联电极帽寿命、焊点强度、车身侧围工序和历史焊核不良案例，建议抽检焊核直径、检查二次线接触电阻、到达阈值后自动触发电极帽更换任务。

### 涂装膜厚与固化风险

智能体发现烘房温度低于工艺窗口，关联涂料批次、膜厚、烘干曲线和附着力缺陷，建议隔离时间窗内在制车，复测膜厚与附着力，并检查温控回路。

## 5. 量化价值

| 指标 | 试点前 | 试点目标 |
| --- | --- | --- |
| 异常定位时间 | 依赖人工跨系统排查 | 下降50% |
| 重复质量问题 | 复盘沉淀不足 | 下降20% |
| 关键工序追溯 | 多系统人工拼接 | 覆盖率100% |
| 处置闭环 | 群消息/人工催办 | 多维表格SLA追踪 |
| 知识复用 | 个人经验为主 | 形成可检索案例库 |
